# Inteligência Artificial do Zero

Um curso de inteligência artificial em português, do zero até um Transformer em miniatura, usando Matemática, Física e Inglês como fio condutor.

## Como estudar

1. Abra cada módulo pelo link "Abrir no Colab" da tabela abaixo. Não precisa instalar nada.
2. Execute as células em ordem, de cima para baixo, com Shift+Enter.
3. Faça os exercícios da seção "Mão na massa" antes de olhar as soluções.
